# Модерация жалоб

В Terms обещано реагировать на жалобы в течение 24 часов, поэтому очередь нужно
смотреть раз в день. Всё делается в Supabase, отдельной админки нет.

Жалобы попадают в таблицу `moderation_reports`: и на пользователя (из его профиля),
и на конкретный пост (меню «…» на посте — тогда `reason` начинается с `post:<id>`).

## Один раз

1. Выполнить миграцию `supabase/migrations/20261014_moderation_handling.sql`
   (добавляет отметку «обработано»).
2. В Supabase → SQL Editor создать сохранённый запрос «Moderation queue» и вставить
   в него блок 1 из `supabase/scripts/moderation_queue.sql`.
3. Поставить себе ежедневное напоминание.

## Каждый день (2–5 минут)

1. Запустить «Moderation queue». Пусто — на сегодня всё.
2. Для каждой строки:
   - есть `post_id` → блок 2 из скрипта, посмотреть пост; фото открывается в
     Storage → `post-photos` по пути из `photo_path`;
   - нет `post_id` → блок 2b, посмотреть посты пользователя, и его профиль в приложении.
3. Решить:
   - **нарушения нет** → закрыть жалобу (блок 4) с пометкой `no violation`;
   - **пост нарушает правила** → удалить пост (блок 3); если вернулся `photo_path`,
     удалить этот файл в Storage → `post-photos`; закрыть жалобу;
   - **грубое или повторное нарушение** (см. колонку `reports_on_user`) → удалить посты
     и заблокировать аккаунт: Authentication → Users → найти по `reported_id` →
     «Ban user»; закрыть жалобу с пометкой `banned`.

## Что считается нарушением

Список из раздела 8 Terms: незаконное, оскорбления и травля, угрозы, откровенно
сексуальный или жестокий контент, спам, чужие личные данные, пропаганда самоповреждения
и расстройств пищевого поведения, выдача себя за другого.

## Если пишут на почту

Жалобы на `onefitgram@gmail.com` обрабатываются так же; в `handled_note` закрытой
жалобы или в ответе на письмо коротко записать, что сделано.
